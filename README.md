# DopamineLord

ARPG isométrico 2D en Godot 4.7.2 que mezcla Diablo 2 (builds, loot, skill tree) con Terraria (mundos por semilla, bosses, coop, progresión por hitos). Coop de hasta 4 jugadores, mando desde el principio.

- Diseño completo y decisiones: [docs/DISENO.md](docs/DISENO.md)
- Reglas para trabajar con Claude: [CLAUDE.md](CLAUDE.md)
- Ideas aparcadas: [docs/IDEAS.md](docs/IDEAS.md)

## Abrir el proyecto

Abre la carpeta con Godot 4.7.2 (escritorio o editor de Android). La escena principal es `scenes/main.tscn`: muestra la versión de Godot y las acciones pulsadas, para probar teclado, ratón y mando.
